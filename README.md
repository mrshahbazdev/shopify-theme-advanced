# Nova Advanced Shopify Theme

A premium Shopify 2.0 theme with modern sections and merchant-friendly customization.

## Features
- Responsive, mobile-first design with CSS custom properties
- Sticky header with mega menu and predictive search
- AJAX cart drawer with dynamic quantity updates
- Advanced product page with swatches, tabs, sticky add-to-cart, and media gallery
- Collection filtering, sorting, and pagination
- Before/after image comparison, countdown timer, testimonials, video, newsletter popup, and age verifier
- Customer account templates (login, register, account, addresses, order, reset password)

## Quick start
1. Install the [Shopify CLI](https://shopify.dev/docs/api/shopify-cli)
2. Clone this repo into your Shopify theme directory
3. Run `shopify theme dev --store your-store.myshopify.com`

## Theme structure
This theme follows the standard Shopify Online Store 2.0 architecture:
- `config/` — theme settings schema and defaults
- `layout/` — theme and password layouts
- `sections/` — reusable sections and section groups
- `snippets/` — reusable Liquid snippets
- `templates/` — JSON and Liquid templates
- `assets/` — CSS and JavaScript
