# Changelog — Nova Advanced

## 1.0.0

### Added
- Shopify Online Store 2.0 base with JSON templates
- Header with mega menu, sticky behavior, cart count, predictive search, mobile menu
- Footer with multi-column menus, newsletter, social icons, payment icons
- Image banner, featured collection, collection list, testimonials, video, rich text, countdown timer, before/after sections
- Product page: gallery + lightbox, thumbnails, sticky ATC, swatches, quantity stepper, trust badges, tabs, social share, related products
- Collection page: product grid, sorting, tag filter, price range filter
- AJAX cart drawer with toast notifications
- Contact, about, FAQ, returns, blog, article, and policy page templates
- Customer account templates (login, register, account, order, addresses, reset password)
- Newsletter popup and age verifier sections
- Full translation support via `locales/en.default.json`
- Accessibility: skip-to-content link, focus-visible styles, ARIA labels, keyboard controls

### Theme Store readiness
- `shopify theme check` 0 offenses
- All customer-facing text is translatable
- Valid image sizing and lazy loading
- Demo store setup guide and submission checklist added
